# FANZA Drive保存（Androidアプリ）

FANZA同人で**購入済みの作品**をスマホでダウンロードし、

1. ファイル名を**作品タイトルに自動リネーム**
2. **Googleドライブ**（または本体の `Download/FANZA` フォルダ）へ**自動保存**

までを、**バックグラウンドで全自動**で行うアプリです。

- FANZA同人はPC版サイトでないとダウンロードできないため、アプリ内ブラウザは常に **PC版表示** になります。
- ダウンロードボタンを押した後はアプリを閉じても処理が続きます（通知に進行状況が出ます）。
- 通信が切れても自動で再試行し、保存済みの作品は記録して二重保存を防ぎます。

---

## 1. APKのダウンロードとインストール

1. スマホのブラウザで、このリポジトリの **[Releases](../../releases)** を開きます。
2. 一番上（最新）のリリースの「Assets」から `FanzaDrive-v1.0.xx.apk` をタップしてダウンロード。
3. ダウンロード完了の通知などから開き、インストールします。
   - 「提供元不明のアプリ」の許可を求められたら、使用中のブラウザに許可を与えてください。
4. 初回起動時の「通知の許可」は **許可** にしてください（保存の進行状況・完了がわかります）。

> 2回目以降は新しいAPKを入れるだけで上書きアップデートでき、ログイン状態や設定はそのまま残ります。

## 2. 使い方

1. アプリを開くとFANZAのページが表示されるので、DMMアカウントで**ログイン**します。
2. 上部の **「購入済み」** を押すと購入済み一覧（PC版）が開きます。
   - 画面が小さいときは、2本指で拡大してください。
3. 作品の **ダウンロードボタン** を押すだけで、あとは全自動です。
   - 作品ページから正式タイトルを取得 → `作品タイトル.zip` にリネーム → 保存
4. **「未保存を一括」** を押すと、表示中のページにあるダウンロードリンクのうち、まだ保存していない作品をまとめて保存します。
   - 設定の「購入済みページを開いたら未保存作品を自動で保存」をONにすると、購入済みページを開くだけで自動的に一括保存します。

| ボタン | 動作 |
|---|---|
| 購入済み | 購入済み作品一覧（PC版）を開く |
| 未保存を一括 | ページ内の未保存作品をまとめて保存予約 |
| 再読込 | ページを再読み込み |
| 設定 | Googleドライブ連携・保存先などの設定 |

## 3. Googleドライブ連携の設定（最初に1回だけ・約5分）

Googleドライブへの保存は、**Google Apps Script（GAS）** という無料の仕組みを中継役に使います。
パソコンでの作業がおすすめですが、スマホのブラウザ（PC版表示）でも可能です。

1. <https://script.google.com/> を開き、Googleアカウントでログインして **「新しいプロジェクト」** を作成。
2. 最初から書かれているコードをすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を丸ごと貼り付けます。
3. 3行目あたりの `const SECRET = 'ここを好きな合言葉に変更';` の部分を、**自分だけが知っている合言葉**（例: `a8Kd93-xQ2` のような推測されにくい文字列）に書き換えて保存（💾）します。
4. 上部の関数選択で **`authorize`** を選び **「実行」**。
   - 「承認が必要です」→ 自分のアカウントを選択 →「詳細」→「（安全ではないページ）に移動」→「許可」。
   - ※自分で作ったスクリプトなので問題ありません。
5. 右上の **「デプロイ」→「新しいデプロイ」** を開き、
   - 種類の選択（⚙）で **「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー。
6. アプリの **「設定」** を開き、
   - 「GASのウェブアプリURL」にコピーしたURLを貼り付け
   - 「合言葉」に手順3で決めた合言葉を入力
   - **「Googleドライブ連携をテスト」** を押して「成功！」と出ればOK →「保存」

保存先は **マイドライブ直下の「FANZA同人」フォルダ** です（自動で作られます）。

> 💡 「アクセスできるユーザー: 全員」でも、合言葉を知らない人は何もできません。合言葉とURLは他人に教えないでください。
> 💡 GASのコードを書き換えたときは「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」で更新してください。

## 4. 設定項目

| 項目 | 説明 |
|---|---|
| GASのウェブアプリURL / 合言葉 | Googleドライブ連携用。未設定なら本体の `Download/FANZA` に保存 |
| スマホ本体にも保存する | ONにするとドライブと本体の両方に保存（OFFならドライブのみ） |
| Wi-Fi接続中のみ処理する | モバイル通信量の節約。Wi-Fiにつながるまで待機します |
| 購入済みページを開いたら自動で保存 | 購入済み一覧を開くだけで未保存作品を一括保存 |
| 保存済み履歴をリセット | 「保存済み」の記録を消して、もう一度保存できるようにする |

## 5. うまくいかないとき

- **「Webページが返されました」と通知が出る** → ログインが切れています。アプリでFANZAにログインし直してください。
- **「未保存を一括」で見つからない** → 一覧を最後までスクロールしてから押すか、各作品のダウンロードボタンを直接押してください（サイトの作りによってはリンクを自動検出できない場合があります）。
- **タイトルが取得できない** → 作品ページが削除されている等の場合は、元のファイル名で保存されます。
- **ドライブ連携テストで失敗** → GASのデプロイ設定（実行ユーザー: 自分 / アクセス: 全員）と合言葉を確認してください。
- 専用ビューアでしか読めない作品（ダウンロードファイルが無い作品）は保存できません。

## 開発者向け

- Kotlin / Android（minSdk 29 = Android 10 以上）
- ブランチにpushすると GitHub Actions（`.github/workflows/build.yml`）が APK をビルドし、Actions の成果物と Releases に公開します。
- 署名鍵: `app/fanzadrive.keystore`（上書きアップデートを可能にするための固定鍵）。独自の鍵を使う場合は Secrets に
  `SIGNING_KEYSTORE_BASE64` / `SIGNING_STORE_PASSWORD` / `SIGNING_KEY_ALIAS` / `SIGNING_KEY_PASSWORD` を登録してください。

| ファイル | 役割 |
|---|---|
| `MainActivity.kt` | PC版表示のアプリ内ブラウザ、ダウンロード検知、一括保存 |
| `DownloadWorker.kt` | バックグラウンドでのダウンロード・リネーム・保存 |
| `TitleResolver.kt` | 作品ID（`d_123456`）から作品ページを見てタイトル取得 |
| `DriveUploader.kt` | GAS経由でGoogleドライブへ分割アップロード |
| `gas/Code.gs` | Googleドライブ側の中継スクリプト |

> 本アプリは、ご自身が正規に購入した作品を個人的にバックアップする目的でご利用ください。
