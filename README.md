# FANZA Drive保存（Androidアプリ）

FANZA同人で**購入済みの作品**をスマホでダウンロードし、

1. ファイル名を**作品タイトルに自動リネーム**
2. **Googleドライブ**（または本体の `Download/FANZA` フォルダ）へ**自動保存**

までを、**バックグラウンドで全自動**で行うアプリです。

- FANZA同人はPC版サイトでないとダウンロードできないため、アプリ内ブラウザは常に **PC版表示** になります。
- ダウンロードボタンを押した後はアプリを閉じても処理が続きます（通知に進行状況が出ます）。
- 通信が切れても自動で再試行し、保存済みの作品は記録して二重保存を防ぎます。

---

## 1. APKのダウンロードとインストール

1. スマホのブラウザで、このリポジトリの **[Releases](../../releases)** を開きます。
2. 一番上（最新）のリリースの「Assets」から `FanzaDrive-v1.0.xx.apk` をタップしてダウンロード。
3. ダウンロード完了の通知などから開き、インストールします。
   - 「提供元不明のアプリ」の許可を求められたら、使用中のブラウザに許可を与えてください。
4. 初回起動時の「通知の許可」は **許可** にしてください（保存の進行状況・完了がわかります）。

> 2回目以降は新しいAPKを入れるだけで上書きアップデートでき、ログイン状態や設定はそのまま残ります。

## 2. 使い方

1. アプリを開くとFANZAのページが表示されるので、DMMアカウントで**ログイン**します。
2. 上部の **「購入済み」** を押すと購入済み一覧（PC版）が開きます。
   - 画面が小さいときは、2本指で拡大してください。
3. 作品の **ダウンロードボタン** を押すだけで、あとは全自動です。
   - 作品ページから正式タイトルを取得 → `作品タイトル.zip` にリネーム → 保存
4. **「一括保存」** を押すと、表示中のページにあるダウンロードリンクのうち、まだ保存していない作品をまとめて保存します。
   - 設定の「購入済みページを開いたら未保存作品を自動で保存」をONにすると、購入済みページを開くだけで自動的に一括保存します。

| ボタン | 動作 |
|---|---|
| 購入済み | 購入済み作品一覧（PC版）を開く |
| 一括保存 | ページ内の未保存作品をまとめて保存予約 |
| 保存状況 | 処理中・順番待ち・完了・失敗の一覧。**一時停止／再開**、**整理**（重複の取り消し）もここから |
| 再読込 | ページを再読み込み |
| 設定 | Googleドライブ連携・保存先などの設定 |

### 便利な仕組み

- **重複の自動除外**: 同じ作品は二重に保存待ちに入りません。保存済みの作品を押したときは「もう一度保存しますか？」と確認します。アプリ起動時には、古いバージョンで二重に予約された分も自動で取り消します。
- **一時停止／再開**: 「保存状況」→「⏸ 一時停止」で全部止まり、「▶ 再開」で**途中から**続きます。
- **アップデートしても止まらない**: 新しいAPKを入れると自動で処理を再開し、ダウンロードもドライブへの送信も途中から続きます。
- 同時に処理するのは2件まで（空き容量を使い切らないため）。残りは順番待ちになります。

## 3. Googleドライブ連携の設定（最初に1回だけ）

保存方式は2種類あり、アプリの「設定」で切り替えられます。**おすすめは方式A（API方式）**です。

| | 方式A：API方式（おすすめ） | 方式B：GAS方式 |
|---|---|---|
| アプリでの操作 | 「Googleでログイン」を押すだけ | URLと合言葉を入力 |
| 最初の準備 | Google Cloud に登録（約10分） | Apps Script を作成（約5分） |
| アクセスできる範囲 | **このアプリが作ったファイルだけ**（安全） | 自分のドライブ全体（スクリプト経由） |

### 方式A：API方式（Googleでログイン）

アプリから直接 Google Drive API を使うために、Google に「このアプリを使います」と1回だけ登録します。
（Googleのルールで、自作アプリがドライブを使うにはこの登録がどうしても必要です）
パソコンでの作業がおすすめです。

1. <https://console.cloud.google.com/> を開き、Googleアカウントでログイン（初回は利用規約に同意）。
2. 画面上部のプロジェクト選択 →「**新しいプロジェクト**」→ 名前（例: `fanza-drive`）を入れて「作成」。作成したプロジェクトを選択しておきます。
3. 上部の検索欄で「**Google Drive API**」を検索 → 開いて「**有効にする**」。
4. 左上のメニュー →「**Google Auth Platform**」（または「APIとサービス」→「OAuth同意画面」）を開き、「開始」を押して入力:
   - アプリ名: `FANZA Drive保存`（何でもOK）／ユーザーサポートメール: 自分のメール
   - 対象（ユーザーの種類）: **外部**
   - 連絡先メール: 自分のメール → 同意して「作成」
5. 「**対象**（Audience）」を開き、公開ステータスの「**アプリを公開**」を押して「本番環境」にします。
   - ※「テスト」のままだと7日ごとにログインし直しが必要になります。
   - ※このアプリが使う権限（drive.file）は審査不要なので、本番環境にしても問題ありません。
6. 「**クライアント**」（または「認証情報」→「認証情報を作成」→「OAuthクライアントID」）→「クライアントを作成」:
   - アプリケーションの種類: **Android**
   - パッケージ名: `com.udonn.fanzadrive`
   - SHA-1 証明書フィンガープリント:
     ```
     E6:21:CD:E4:2C:C0:6B:D8:D0:EF:BA:3C:08:1A:D8:C1:DA:EE:48:EB
     ```
   - 「作成」を押します（表示されるクライアントIDはメモ不要です）。
7. スマホのアプリで「**設定**」→「API方式」を選択 →「**Googleでログイン**」→ アカウントを選んで「許可」。
   「ログイン中: (メールアドレス)」と表示されたら完了です。「保存」を押して閉じてください。

> 💡 登録直後は反映に数分かかることがあります。「Google Cloudの設定が見つかりません」と出たら、5〜10分待ってから再度ログインしてください。
> 💡 「このアプリは Google で確認されていません」と表示された場合は「詳細」→「（アプリ名）に移動」で進めます（自分で登録したアプリなので問題ありません）。

保存先は **マイドライブ直下の「FANZA同人」フォルダ** です（アプリが自動で作ります）。

### 方式B：GAS方式（Google Apps Script）

Google Cloud への登録をしたくない場合はこちら。**Google Apps Script（GAS）** という無料の仕組みを中継役に使います。

1. <https://script.google.com/> を開き、Googleアカウントでログインして **「新しいプロジェクト」** を作成。
2. 最初から書かれているコードをすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を丸ごと貼り付けます。
3. 3行目あたりの `const SECRET = 'ここを好きな合言葉に変更';` の部分を、**自分だけが知っている合言葉**（例: `a8Kd93-xQ2` のような推測されにくい文字列）に書き換えて保存（💾）します。
4. 上部の関数選択で **`authorize`** を選び **「実行」**。
   - 「承認が必要です」→ 自分のアカウントを選択 →「詳細」→「（安全ではないページ）に移動」→「許可」。
5. 右上の **「デプロイ」→「新しいデプロイ」** を開き、
   - 種類の選択（⚙）で **「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**／アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー。
6. アプリの「設定」→「GAS方式」を選び、URLと合言葉を入力 →「GAS連携をテスト」で「成功！」と出たら「保存」。

> 💡 合言葉とURLは他人に教えないでください。

## 4. 設定項目

| 項目 | 説明 |
|---|---|
| 保存方式（API / GAS） | Googleドライブ連携の方式。どちらも未設定なら本体の `Download/FANZA` に保存 |
| スマホ本体にも保存する | ONにするとドライブと本体の両方に保存（OFFならドライブのみ） |
| Wi-Fi接続中のみ処理する | モバイル通信量の節約。Wi-Fiにつながるまで待機します |
| 購入済みページを開いたら自動で保存 | 購入済み一覧を開くだけで未保存作品を一括保存 |
| 保存済み履歴をリセット | 「保存済み」の記録を消して、もう一度保存できるようにする |

## 5. うまくいかないとき

- **「Webページが返されました」と通知が出る** → ログインが切れています。アプリでFANZAにログインし直してください。
- **「一括保存」で見つからない** → 一覧を最後までスクロールしてから押すか、各作品のダウンロードボタンを直接押してください（サイトの作りによってはリンクを自動検出できない場合があります）。
- **タイトルが取得できない** → 作品ページが削除されている等の場合は、元のファイル名で保存されます。
- **「Google Cloudの設定が見つかりません」** → 方式Aの手順6のパッケージ名・SHA-1が正しいか、手順3でDrive APIを有効にしたか確認してください。
- **「Googleの再ログインが必要です」** → 設定から「Googleでログイン」をもう一度押してください（公開ステータスが「テスト」のままだと7日ごとに発生します）。
- **GAS連携テストで失敗** → GASのデプロイ設定（実行ユーザー: 自分 / アクセス: 全員）と合言葉を確認してください。
- 専用ビューアでしか読めない作品（ダウンロードファイルが無い作品）は保存できません。

## 開発者向け

- Kotlin / Android（minSdk 29 = Android 10 以上）
- ブランチにpushすると GitHub Actions（`.github/workflows/build.yml`）が APK をビルドし、Actions の成果物と Releases に公開します。
- 署名鍵: `app/fanzadrive.keystore`（上書きアップデートを可能にするための固定鍵。API方式のSHA-1登録にも使用）。独自の鍵を使う場合はSHA-1も登録し直したうえで Secrets に
  `SIGNING_KEYSTORE_BASE64` / `SIGNING_STORE_PASSWORD` / `SIGNING_KEY_ALIAS` / `SIGNING_KEY_PASSWORD` を登録してください。

| ファイル | 役割 |
|---|---|
| `MainActivity.kt` | PC版表示のアプリ内ブラウザ、ダウンロード検知、一括保存 |
| `DownloadWorker.kt` | バックグラウンドでのダウンロード・リネーム・保存 |
| `TitleResolver.kt` | 作品ID（`d_123456`）から作品ページを見てタイトル取得 |
| `GoogleAuth.kt` | Googleログイン（drive.file 権限のアクセストークン取得） |
| `DriveUploader.kt` | Drive API／GAS経由でGoogleドライブへ分割アップロード |
| `gas/Code.gs` | GAS方式用の中継スクリプト |

> 本アプリは、ご自身が正規に購入した作品を個人的にバックアップする目的でご利用ください。
